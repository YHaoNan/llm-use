# SDK 与 Demo（GitHub 摘录）

更新时间：2026-02-05  
来源：https://github.com/next-space/flowus-api-sdk

## 作用

如果你要自建 MCP Server，SDK/Demo 主要价值在于：

- 提供可运行的“真实请求样例”（创建数据库/记录、搜索、块追加等）
- 暗示 API 的 OpenAPI 规范存在（便于生成类型与客户端）

## 原文抓取（页面文本）

FlowUs API - 多语言 SDK 和演示项目
FlowUs API 的多语言客户端 SDK，包含完整的演示项目。
支持的语言：Java、TypeScript/JavaScript 等
项目结构：包含 openapi.json、typescript-demo、java-demo、生成的 sdk 等
快速开始：获取 FlowUs API Token、运行 demo
SDK 使用：Java/TypeScript 初始化 bearer token
安全注意事项：不要硬编码 Token、用环境变量等
